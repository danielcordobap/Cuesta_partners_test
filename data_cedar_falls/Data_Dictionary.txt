HOUSING DATASET — DATA DICTIONARY
========================================================================

Records in this file: approximately 2,960 individual property sales in
Cedar Falls, Iowa, covering the period 2006-2010.

Every code listed below is GUARANTEED to appear in Data.csv. Where the
dataset uses an extended code (e.g. "A (agr)" instead of "A"), this
dictionary uses the form that actually appears in the file.

========================================================================
NOTES ON MISSING VALUES (NaN) IN THE ORIGINAL SOURCE
========================================================================
In the original dataset, NaN values in the following columns
are NOT errors — they mean the feature genuinely does not exist for that
property:

  Pool QC        NaN = no pool
  Misc Feature   NaN = no extra feature
  Alley          NaN = no alley access
  Fence          NaN = no fence
  Fireplace Qu   NaN = no fireplace
  Mas Vnr Type   NaN = no masonry veneer
  Garage Type    NaN = no garage  (and the rest of Garage * columns)
  Bsmt Qual      NaN = no basement  (and the rest of Bsmt * columns)

NaN values in any other column may indicate a data quality issue worth
investigating.
